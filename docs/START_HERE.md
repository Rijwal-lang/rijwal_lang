## ⚡ Quick Start (2 Minutes)

### Step 1: Setup
```bash
python setup.py
```
This installs everything you need.

### Step 2: Start IDE
```bash
python ide_server.py
```

### Step 3: Open Browser
Go to: **http://localhost:5000**

### Step 4: Write Code
```rijwal
When Program Starts:
    Print "Hello, World!"
```

### Step 5: Run
Click **▶️ Run Code**

**Done!** You're now a programmer! 🎉

## ❓ FAQ

### How do I install it?
```bash
python setup.py
```

### How do I start the IDE?
```bash
python ide_server.py
```

### Where do I write code?
Open `http://localhost:5000` in your browser

### How do I save my code?
Use the 💾 Save button or save in the IDE (uses browser storage)

### Can I run code offline?
No, but the IDE works offline once loaded. Code execution needs Python running.

### What if I get an error?
Read the error message - it tells you the line number and problem!

### Can I use Python code?
Yes! Use Python blocks:
```rijwal
Python:
    import math
    x = math.sqrt(16)
```

### Can I use JavaScript?
Yes! Use JS blocks (requires Node.js):
```rijwal
JS:
    console.log("Hello")
```
