# Rijwal_Lang

Rijwal_Lang is a friendly, high-level, AI-assisted programming language and
platform focused on simplicity, flexibility, and learning.

## Features
- Case-insensitive syntax
- Python and JavaScript interoperability
- Optional AI assistance (local-first)
- External no-code bridges (e.g., Node-RED)
- Beginner-friendly and extensible
