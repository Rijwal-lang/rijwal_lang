How to Use Rijwal_Lang

Requirements:
- Python 3.10 or newer
- Windows / Linux / macOS

Basic Run:
1. Open a terminal in the project folder
2. Run:
   python rijwal_lang.py examples/hello.Rijwal_Lang

Examples:
- Explore the `examples/` folder
- Files are case-insensitive
- Python and JS interop is supported where enabled

Optional:
- Enable AI assistance if configured
- Use external no-code tools (Node-RED) if desired
